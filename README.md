# Nexus-Assessment-Studio

A unified intelligence system for generating, evaluating, and analyzing assessments using AI.

## 🚀 Modules

- **Smart Generation** – Dynamic question creation
- **Assessment Studio** – Interactive evaluation layer
- **Nexus** – Core intelligence layer connecting all components

## 🧠 Features

- Curriculum & JD-based assessment generation
- Skill extraction and validation
- Gamification & hint system
- Document parsing (PDF, text)

## ⚙️ Tech Stack

- FastAPI
- Python
- OpenAI API
- HTML/CSS/JS
